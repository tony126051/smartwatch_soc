# Smartwatch SoC KWS アクセラレータ レジスタマップ (Register Map)

[繁體中文](../register_map.md) | [English](../en/register_map.md) | [日本語](register_map.md)

ベースアドレス：`0x4000_0000`  
バスプロトコル：AMBA APB (32-bit データバス)

| オフセット | レジスタ名 | アクセス | リセット値 | フィールド説明 |
|---|---|---|---|---|
| `0x000` | **AFE_CTRL** | R/W | `0x0000_0000` | **[0]**: オーディオフロントエンド & CIC フィルタ有効化 (1 = 有効, 0 = 無効) |
| `0x004` | **AFE_STATUS** | RO | `0x0000_0001` | **[0]**: FIFO 空フラグ (`empty`)<br>**[1]**: FIFO 満フラグ (`full`)<br>**[16:8]**: FIFO 現在サンプル数 (`count`) |
| `0x008` | **AFE_DATA** | RO | `0x0000_0000` | **[15:0]**: 16-bit PCM 音声データの読出 (読出後自動 Pop) |
| `0x010` | **VAD_CTRL** | R/W | `0x0000_0000` | **[0]**: VAD モジュール有効化<br>**[1]**: 1 書込みで VAD 起動割込みフラグ (`irq_vad_wakeup`) をクリア |
| `0x014` | **VAD_THRESHOLD** | R/W | `200000` | **[23:0]**: 短時間エネルギー (STE) 判定閾値 |
| `0x018` | **VAD_HANGOVER** | R/W | `3` | **[3:0]**: Hangover デバウンスフレーム数 (音節途切れ防止) |
| `0x01C` | **VAD_ENERGY** | RO | `0x0000_0000` | **[23:0]**: 現フレームの累積短時間エネルギー<br>**[24]**: 音声アクティビティ状態 (`speech_active`) |
| `0x020` | **NPU_CTRL** | R/W | `0x0000_0000` | **[0]**: 推論開始パルス (`start_inference`)<br>**[1]**: 1 書込みで NPU 完了割込みフラグ (`irq_npu_done`) をクリア |
| `0x024` | **NPU_STATUS** | RO | `0x0000_0000` | **[0]**: NPU 演算中 (`busy`)<br>**[1]**: 推論完了 (`done`)<br>**[2]**: キーワード検出成功 (`keyword_detected`) |
| `0x028` | **NPU_SCORE0** | RO | `0x0000_0000` | **[31:0]**: クラス 0 (非キーワード/背景ノイズ) 分類スコア (符号付き 32-bit 整数) |
| `0x02C` | **NPU_SCORE1** | RO | `0x0000_0000` | **[31:0]**: クラス 1 (ターゲットキーワード) 分類スコア (符号付き 32-bit 整数) |
| `0x400 - 0x4FF` | **NPU_FEAT_RAM** | R/W | `0x00` | 256 バイト INT8 入力特徴マップアクセスウィンドウ ($16\times16$) |
| `0x500 - 0x5FF` | **NPU_WGT_RAM** | R/W | `0x00` | 256 バイト INT8 ニューラルネットワーク重みアクセスウィンドウ |
